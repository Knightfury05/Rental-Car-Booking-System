# Rental Car Booking System 
This project is a full-stack car rental management system built with **Spring Boot**, **MySQL**, and **Thymeleaf**.  
It allows users to:
- View available cars  
- Upload car images (via Cloudinary)  
- Book cars and manage reservations  
- Admins can add, update, and delete cars  

## Tech Stack
- Backend: Spring Boot (MVC, JPA, Security)
- Frontend: Thymeleaf, HTML, CSS
- Database: MySQL
- Image Hosting: Cloudinary
